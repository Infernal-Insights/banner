Example project

Open books

A group wants the public record on government and nonprofit spending to be something a stranger can rebuild, not a claim they have to take on faith. This page is what someone reads before they contribute a computer. It is an example, not a live project.

Why contribute your computer

A payment only matters if the paperwork agrees.

Your computer takes one official file: a payment list, a license roll, a nonprofit filing, a corporate record. It links the names and addresses that file actually supports. A different computer is given the same file and does it again. If the links match, that slice goes into the map, and your vote in the project goes up.

The map is how the group decides which program or which state to open next. It does not decide that someone committed a crime. A lead is a set of documents and the links between them, so a reporter, an auditor, or a prosecutor can start from the same files. The vote cannot be bought.

  • Rebuild the map from the source files, not from a summary.
  • Ask agencies for records with one request the members have already approved, not a flood.
  • Keep every source file, so a claim can be checked or thrown out.

What your computer does

One file, then it waits.

When that file has been linked and checked, your cores stop. A model that reads the filings can use a GPU, and only if you turn it on for this project. It can draft a note that cites the file. It cannot declare anyone guilty, and the note is dropped if a second computer cannot find the same citation.

Joining

A link opens the app.

On a real project, Join adds it to the app on your computer. You then pick how many cores it may use, and whether it may use a GPU. This example has nowhere to send that work yet.
