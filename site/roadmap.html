Roadmap

The vote stays on the computer that did the work.

We call that vote sway. It is a count, not a coin. It goes up when your computer finishes a task and another computer agrees. You cannot send it to someone else, and you cannot buy more of it.

A wallet such as MetaMask can approve a decision, or send ETH if a project is raising money for extra computers. It does not hold your votes. The project itself is kept by the people who joined, so it does not die with the founder or with this website. That shared copy is not built yet.

Two different things

Where it livesWhat it does
Your vote The Banner app, on your computer Counts the work this computer finished for one project. Stays here.
Your wallet MetaMask, or another Ethereum wallet Approves a change to the project, or pays ETH into it. Optional.

What members can decide

DecisionWhat changes
InstructionsThe written directions every helper for the project has to follow.
HelperWhich small model those computers run, the same one for everyone.
EditorWho may publish a note. They are not required for the work to continue.
Allowed tasksThe kinds of work members' computers are willing to run.
Extra computersWhether the project may spend ETH to rent more machines, and how much.

A helper, not a boss

A project can run a small assistant on the computers of people who opt in, all of them using the same model and the same instructions the members voted for. It runs when there is a lull. It can suggest the next tasks, point out work that failed the second check, or draft an update.

It cannot declare work finished, remove someone, or post in public by itself. An update stays a draft until members vote to publish it. If there is nothing honest to add, the project stays quiet.

What we build, in order

  1. Now

    This site, and a way to write the project you want people to join.

  2. Next

    The app. Several projects, a core limit for each, GPU switches, and a stop when there is nothing to do. A project link opens it.

  3. Then

    A shared record every member keeps. MetaMask can sign. The vote still cannot be transferred. The founder does not have to be online for the next task to be posted.

  4. After that

    Real tasks in containers. A check that a computer can do the job before it takes GPU work. Rented machines, if a project pays for them, get paid and do not get a vote. The assistant comes last, and only as a suggestion.
