Reef map

This is the reference project in the repository, published here so a real banner has a shape to copy. It is not asking for your GPU tonight.

Why stand under it

See a vote happen, in a picture.

The map is split into tiles. Your machine renders one. A different machine renders it again. If the bytes match, your sway on this banner goes up by one. You can look at the mosaic and see which tiles are real.

  • Prove a stranger can take a task and a second machine can check it.
  • Show sway moving only when the check agrees.
  • Be the bill a new project copies when it writes its own.
image banner-tile:1 grid 2×2 queue empty in the demo once it finishes

What a machine actually does

Render a tile from a seed.

No account. No open port. The task is done when the hash matches a recomputation, not when someone says it looks fine.
