The app

Your computer, pointed at the projects you chose.

You install Banner once. A project link opens it and adds that project. You can support several at the same time. Each one gets only the cores and the GPUs you allow.

You set the limit per project.

Four cores for the river. Two for the archive. A GPU turned on for one project is off for the others. Nothing runs on a graphics card until you say so.

A quiet week is normal.

Most projects will not have work every hour. When the list is empty, Banner stops. Those cores are yours until there is something real to do.
